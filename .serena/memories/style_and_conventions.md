# Style and Conventions

Based on the existing codebase, the following conventions are used:

-   **Naming:**
    -   Use camelCase for variables and functions.
    -   Use PascalCase for types and interfaces.
-   **Type Hinting:**
    -   Type hints are used consistently throughout the codebase.
-   **Docstrings:**
    -   Docstrings are not consistently used, but it is recommended to add them for complex functions.
-   **Modules:**
    -   The code is organized into modules using ES modules (`import`/`export`).
