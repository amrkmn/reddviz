# Task Completion Guidelines

When a task is completed, the following steps should be taken:

1.  **Linting and Formatting:**
    -   There are no explicit linting or formatting commands defined in `package.json`. It is recommended to add them to ensure code quality and consistency.
2.  **Testing:**
    -   There are no testing commands or frameworks set up in the project. It is recommended to add a testing framework (e.g., Vitest) to ensure the application's correctness.
3.  **Deployment:**
    -   Once the code has been tested and linted, it can be deployed to Cloudflare Workers using the `bun run deploy` command.
